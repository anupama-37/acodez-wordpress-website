# VSRP – Engineered Rubber (WordPress + Elementor)

Machine test: Figma homepage recreated in WordPress using Elementor (free) and Hello Elementor theme.

Live site: <deployed link ivide>

## Files
- custom.css : Additional CSS used on the site
- elementor-home.json : Elementor home page export
- screenshots

## Setup
1. Install WordPress, Elementor and Hello Elementor theme
2. Elementor → Templates → Import Templates → elementor-home.json
3. Appearance → Customize → Additional CSS → paste custom.css
